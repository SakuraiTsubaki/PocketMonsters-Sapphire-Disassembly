# Sapphire Japanese revision 0 layout measurement

The 8 MiB Japanese origin candidate is measured as eight 1 MiB regions. The JSON report records hashes, entropy, byte counts, GBA ROM/Thumb-pointer candidates, and ARM branch-word candidates. Region 0 is only `header-and-entry`; regions 1–7 remain `unclassified`, because bit-pattern counts alone cannot prove code or data boundaries. All regions are non-uniform. No ROM bytes are stored and the release remains a `candidate`.
