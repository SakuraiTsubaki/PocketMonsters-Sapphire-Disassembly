# Sapphire release candidates

This foundation pass records the Japanese origin release and English revisions 0, 1, and 2 observed locally. The Japanese image is 8 MiB with game code `AXPJ`; all three English revisions are 16 MiB with game code `AXPE`.

Every entry passed the shared GBA inspector's Nintendo logo, fixed-value, reserved-area, and header-checksum validation. All remain `candidate`: header integrity is not independent retail provenance, and GBA provides no whole-ROM global checksum. Independent corroboration or a reproducible matching build is required before promotion to `verified`.

No ROM binary or byte extract is included.
