# Global title-screen Kyogre tile provenance

The Japanese, English, German, French, Italian, and Spanish revision-0 ROMs
store the same 1,540-byte compressed Kyogre stream at different offsets.
Every stream decompresses to the same 8,192-byte 4bpp tile set, SHA-256
`8459431a41689af67a8e6607b7b7e91969e519e94d93c2d65afa332b937cf9f6`.

Language-specific extraction reports and rendered PNGs are retained so each
official release remains independently reproducible. There was no official
Korean Generation III release. Equal output hashes demonstrate identical tile
and palette inputs. No ROM bytes are published.
