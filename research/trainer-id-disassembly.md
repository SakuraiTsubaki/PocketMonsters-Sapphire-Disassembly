# Pokemon Sapphire trainer-ID helper disassembly

The Japanese release `axp-j-rev0-retail` is the independent origin reference for this Disassembly axis. Its verified Thumb function ranges were matched uniquely and adjacently in all 12 cataloged releases (Japanese, English, German, French, Italian, Spanish). The source records the four-byte little-endian helper behavior; per-release maps and publication-safe CFGs prove addresses, boundaries, and code hashes without publishing ROM instruction bytes.
